Assignment 6.3: Overflow & Layout Fixing

1. overflow: visible

This box has overflow: visible. The content inside is longer than the container height, so it overflows and spills out into the surrounding page elements below it without adding scrollbars.

2. overflow: hidden

This box has overflow: hidden. The content inside is longer than the box height, so any extra text that exceeds 120px height is clipped and completely hidden from view.

3. overflow: scroll

This box has overflow: scroll. Scrollbars are permanently shown on both axes (horizontal and vertical), allowing users to scroll through the overflowing text content.

4. overflow: auto

This box has overflow: auto. Scrollbars appear dynamically only when the text content exceeds the box dimensions, providing a clean user interface.

Key Concepts Summary for Submission overflow: visible: Default value. Content is not clipped and renders outside the container box. overflow: hidden: Content that extends past the container size is clipped and hidden without providing scrollbars. overflow: scroll: Clips content and forces the browser to render scrollbars regardless of whether the content actually overflows. overflow: auto: Clips content only if necessary and automatically adds scrollbars only when the content exceeds the container boundaries.
